# Color Changer 🎨

## About the Project

Color Changer is a simple beginner-friendly JavaScript project that changes the background color of a box whenever the user clicks a button.

The project helps beginners understand JavaScript functions, random numbers, and DOM manipulation.

## Features

- Displays a colored box.
- Changes the box color when the button is clicked.
- Generates random colors.
- Uses JavaScript to interact with HTML elements.

## Technologies Used

- HTML – Creates the webpage structure.
- CSS – Styles the webpage and color box.
- JavaScript – Generates random colors and handles button clicks.

## Project Structure

- `index.html` – Contains the webpage structure.
- `style.css` – Contains the styling.
- `script.js` – Contains the JavaScript functionality.
- `README.md` – Explains the project.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Click the **Change Color** button to generate a new color.
